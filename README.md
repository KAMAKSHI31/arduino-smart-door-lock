
# Smart Door Lock System Using Arduino UNO

## Project Overview
An electronic door lock system that uses a keypad
to enter a password and a servo motor to control
a model door lock.

## Components Used
- Arduino UNO
- 4x4 Matrix Keypad
- SG90 Servo Motor
- Breadboard and Jumper Wires
- USB Cable

## Software Used
- Arduino IDE
- Embedded C/C++

## Working Principle
The user enters a password using the keypad.
Arduino checks the password against the stored
value. If it matches, the servo unlocks the model
door for five seconds and then locks it again.

## Features
- Password-based access
- Automatic relocking
- Incorrect-password rejection

## Future Improvements
- LCD status display
- RFID authentication
- Failed-attempt limit
